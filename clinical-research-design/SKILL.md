# Clinical Research Design（可复现版）

## 前置门禁
1. 明确研究类型：RCT / 队列 / 病例对照 / 横断面
2. 声明主要终点：必须预先定义，禁止后验替换
3. 若涉及预测/诊断：同步触发 TRIPOD+AI / STARD 前置清单

## 执行步骤

### 1. 研究类型与统计匹配
| 研究类型 | 因果推断强度 | 适用场景 | 常见统计 |
|----------|--------------|----------|----------|
| RCT | 强 | 干预效果评价 | Logistic/Cox/方差分析 |
| 队列研究 | 中强 | 危险因素/预后 | Cox/回归/率比 |
| 病例对照 | 中 | 罕见病/危险因素 | Logistic/OR |
| 横断面 | 弱 | 患病率/相关性 | 卡方/相关/回归 |

### 2. 样本量计算
- 二分类结局：两组率比较
- 连续结局：均值比较
- 生存结局：log-rank 检验
- 诊断效能：AUC 假设检验
- 公式核心：n = (Z_α + Z_β)^2 * σ^2 / δ^2 类结构
- 必须考虑脱落率（通常 10-20%）

### 3. 基线表（强制 SMD）
- 必须报告全部关键协变量（年龄、性别、分期、合并症、主要治疗）
- 连续变量：均值 ± SD 或 中位数（IQR），附检验方法（t / Mann-Whitney / KS）
- 分类变量：频数（百分比），附检验方法（卡方 / Fisher）
- 报告标准化均值差异（SMD）或标准化差异，|SMD| < 0.1 视为小差异
- **禁止仅凭 P > 0.05 断言“基线可比”**；大样本下 P 值易显著，应以 SMD 为主

### 4. 混杂控制层级
1. 随机化（RCT）
2. 限制入组条件
3. 配对设计
4. 倾向评分匹配（PSM）
5. 多因素回归调整
6. 分层分析 / 亚组分析
7. 敏感性分析

### 5. 偏倚识别
| 偏倚类型 | 来源 | 控制方法 |
|----------|------|----------|
| 选择偏倚 | 入组不随机 | 明确入排、多中心 |
| 信息偏倚 | 测量/回忆偏差 | 盲法/客观指标/统一培训 |
| 混杂偏倚 | 未控制第三变量 | 回归/匹配/分层 |
| 发表偏倚 | 阳性结果易发表 | Egger/Begg/Trim-fill |

### 6. 质量评价工具
- RCT：Cochrane Risk of Bias 2
- 队列：Newcastle-Ottawa Scale (NOS)
- 病例对照：NOS
- 诊断性：QUADAS-2
- 预测模型：TRIPOD
- Meta分析：AMSTAR 2

## 输出
- 研究设计合理性评估
- 样本量计算报告
- 偏倚控制清单
- 质量评价结果
- 基线表（含 SMD）
- provenance.json

## 边界
不包含具体统计建模和绘图；偏重于“研究是否可发表”的方法学审查。
