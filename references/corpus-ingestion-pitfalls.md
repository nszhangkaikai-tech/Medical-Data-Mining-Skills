# 语料抓取与正文提取注意事项

## 问题

`info.helixlife.cn` 文章列表页存在动态加载，HTML 直接抓取得到的正文夹杂大量 CSS/脚本标签，信噪比很低，不适合直接用于主题分析或技能反推。

## 结论

- 列表页可用于枚举 URL 和提取标题
- 正文应优先使用 `web_extract` 获取干净 markdown
- 对 600+ 篇文章不要逐篇精读，应按主题聚类后抽样

## 推荐做法

1. 用 `web_extract` 读取文章详情页
2. 先读标题，按标题聚类
3. 按聚类缺口抽样精读
4. 用聚类结果反推进技能仓库

## 不推荐做法

- 用 requests + BeautifulSoup 直接剥正文标签（会混入大量 CSS）
- 对 600+ 篇文章逐篇生成全文摘要
- 把文章总量直接等同于可枚举 URL 数（可能包含分类/标签聚合条目）
