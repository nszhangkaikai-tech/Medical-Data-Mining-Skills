# 合规报告模板（可复现性与报告规范版）

> 本模板必须配合 `references/reproducibility-and-reporting-standards.md` 和 `references/provenance-schema.md` 使用。

## 1. 报告头部（强制）

```markdown
# {研究标题}

**研究类型**: {来自路由表的唯一主类型}
**数据模式**: real / simulated / not_collected
**数据路径**: {绝对路径或 N/A}
**主要终点**: {预先定义，禁止后验替换}
**金标准/结局变量**: {变量名}
**删失编码**: {0=删失,1=事件 或反之，仅生存}
**分析日期**: {ISO-8601}
**代码/依赖**: {Python/R 版本及关键包}
**随机种子**: {所有 seed}

<!-- DEMO_WATERMARK_START -->
> [!WARNING]
> **DEMO / 模拟数据声明**：本报告包含模拟生成的数据和/或硬编码演示值。所有数值仅用于工作流演示，不得用于临床决策、基金申请或学术发表。
<!-- DEMO_WATERMARK_END -->
```

## 2. 适用报告清单（逐项填写）

```markdown
## 适用规范与完成情况

|------|------|------|-----------------|
| STROBE | | | |

| PROBAST+AI | | | |
| PRISMA 2020 | | | |
| REMARK | | | |
| STARD 2015 | | | |
```

## 3. 数据一致性校验（必须通过）

```markdown
## 数据一致性校验

- [ ] 终点类型与指标匹配：{诊断AUC / 预后C-index / 治疗效应HR}
- [ ] 删失编码一致性：{是/否}
- [ ] 训练/验证/测试隔离：{是/否}
- [ ] 外部验证状态：{completed / pending / not_planned / unavailable}
- [ ] 无数据泄漏证据：{是/否}
- [ ] 基线表报告全部关键变量及 SMD：{是/否}
```

## 4. 分析结果（单一数据源渲染）

所有表格必须从同一已验证结果对象（DataFrame / JSON / R object）渲染，禁止硬编码或跨来源复制数值。

```markdown
## 分析结果

### 4.1 描述性统计
{表}

### 4.2 主要分析
{表 + 图}

### 4.3 验证
{表}

### 4.4 功能注释
{表 + 图}
```

## 5. Provenance（机器可读）

见 `provenance.json`。

## 6. 局限性声明（强制）

```markdown
## 局限性

- 样本量：{N}，事件数：{events}，EPV = {epv}
- 研究设计：{观察性/实验性，单中心/多中心}
- 外部验证：{状态}
- 未控制的混杂：{列举}
- 缺失数据处理：{方法}
- 模拟数据限制（如适用）：{说明}
```

## 7. 结论（必须与局限性匹配）

```markdown
## 结论

{结论必须严格基于已呈现数据，不得超出统计证据范围。若为模拟数据，必须包含“本结论仅为演示，待真实数据验证”}
```
