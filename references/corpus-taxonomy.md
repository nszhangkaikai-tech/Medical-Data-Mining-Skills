# 文章库主题分类与抽样阅读策略

## 适用场景

当面对数百篇文章列表时，目标是建立主题 taxonomy，而不是逐篇生成摘要。

## 推荐流程

1. 枚举全量 URL 并去重
2. 按标题做高置信主题聚类
3. 对每个聚类抽样精读正文
4. 汇总分类脑图与缺口清单

## 抽样策略

- 首屏/前几页先全文精读
- 后续页面按固定间隔抽样（如每 10 篇取 1 篇）
- 对高价值聚类提高抽样密度

## 输入质量要求

- 优先使用 `web_extract` 获取干净 markdown
- 避免使用 HTML 直接剥标签的结果（信噪比低）

## 常见错误

- 把文章总量误当成可枚举 URL 数（页面计数 vs 实际文章数可能不一致）
- 对超大语料逐篇精读，成本不可控
- 用低质量文本做聚类，导致主题归类不准
