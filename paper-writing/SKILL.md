# Paper Writing

## 触发条件
用户提到“论文写作”“方法学报告”“审稿回复”“图表合规”“PRISMA”“Tripod”。

## 输入
- 研究类型 / 分析结果
- 目标期刊风格（可选）
- 审稿意见列表（可选）

## 执行步骤

### 1. 结果整理成“故事线”
1. 一句话概括研究目的
2. 列出核心发现（3-5个）
3. 按“问题→方法→结果→结论”排序

### 2. 方法学报告 checklist
| 研究类型 | 必备报告项 |
|----------|-----------|
| RCT | CONSORT + 随机化/盲法/ITT |
| 队列/病例对照 | STROBE + 入排/随访/失访 |
| 诊断性 | STARD + 金标准/阈值/灵敏度特异度 |
| 预测模型 | TRIPOD + 开发/验证/校准/DCA |
| Meta分析 | PRISMA 2020 + 检索/筛选/异质性/偏倚 |
| 生信分析 | 数据源/预处理/差异筛选/富集/验证 |

### 3. 图表合规检查
- 图注完整（标题/标目/图例/统计量）
- 坐标轴单位统一
- 误差线类型明确（SD/SEM/CI）
- 显著性标注一致（* / ** / ***）
- 配色可打印（灰度友好）

### 4. 审稿回复框架
1. 逐条回应审稿意见
2. 引用修改位置（行号/页码）
3. 补充额外实验或解释
4. 礼貌但坚定地辩护正确结论

### 5. 投稿信要点
- 研究亮点（3个）
- 适合期刊的理由
- 无利益冲突声明
- 作者贡献分工

## 输出
- 结构化论文初稿（IMRD）
- 方法学报告 checklist 完成情况
- 审稿回复要点
- 图表合规检查表

## 边界
不提供学术伦理/一稿多投等不当服务；只做规范写作与表达优化。
